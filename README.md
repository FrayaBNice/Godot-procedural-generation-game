Fraya Procedural Generation Game

* Features
FPS movement: use the Mouse to control the camera, use WASD to move, and Shift to sprint.
Weapons: Left Click to shoot, 1 for Pistol, 2 for Shotgun (there's a pickup in the testing area), 3 for Chaingun.
Enemies: Melee enemy, can't damage the player as the logic for handling the player's death hasn't been implemented.
Procedural Dungeon: Room and hallway generation have been implemented, while entity spawning is still being worked on.
